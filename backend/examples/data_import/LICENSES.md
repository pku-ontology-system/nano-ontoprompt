# 演示数据的来源和许可

| 目录 | 来自 | 许可 |
|---|---|---|
| `abt_buy/Abt-Buy.zip` | 莱比锡大学数据库组的实体消歧基准数据集 [Benchmark datasets for entity resolution](https://dbs.uni-leipzig.de/research/projects/benchmark-datasets-for-entity-resolution)：Abt 和 Buy 两家网店的商品，附已知的同款对 | 知识共享（页面要求引用该网站和论文 Köpcke, Thor, Rahm: *Evaluation of entity resolution approaches on real-world match problems*, VLDB 2010） |
| `beans/` | Hugging Face 的 [AI-Lab-Makerere/beans](https://huggingface.co/datasets/AI-Lab-Makerere/beans) 训练集：从三个类别里各均匀取 20 张，共 60 张照片和标签 | MIT |
| `nyc_taxi/taxi_zone_lookup.csv` | 纽约市出租车和豪华轿车委员会（NYC TLC）的出租车区域对照表 | NYC TLC 公开数据 |

2026-11-10 经用户同意后下载。SHA-256 在各自的加载代码里核对（beans 的在 `beans/manifest.json`）。
