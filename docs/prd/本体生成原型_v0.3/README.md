# 本体生成原型 v0.3

作者：Jie Zhang · 2026-11-24

在 v0.2 的基础上，只加了一个页面：「**应用搭建**」。双击 `index.html` 就能打开，不用联网，也不连后端。

## 页面

| 页面 | 内容 | 本版变化 |
|---|---|---|
| 数据源 `#sources` | 连接数据中台；勾选表；一键生成普通、时序或动态本体 | 不变 |
| 本体总览 `#ontology` | 五种视图、详情、持续更新、结构变化提示 | 不变 |
| **应用搭建** `#workshop` | 专员从模块库挑模块、选位置，搭出各企业自己的本体展示页 | **新增** |

## 应用搭建能做什么

### 模块库（34 个，分 7 组）

| 分组 | 模块 |
|---|---|
| 概览 | 本体信息栏*、本体指标卡、类型实例占比、生成入口 |
| 结构 | 类型图*、数据结构*、关系矩阵*、详情面板*、类型层级树、属性清单表、类型卡片（可多次）、关系清单、关系弦图、本体说明书 |
| 实例 | 实例星图*、实例表格（可多次）、实例详情卡（可多次）、邻居网络 |
| 时间与变化 | 时间视图*、变化流*、结构变化提示*、每日变化量、变化日历、测点时序、版本记录 |
| 质量与来源 | 识别方式分布、待确认关系、本体健康检查、来源血缘、字段映射表 |
| 上下游 | 上游 · 中台同步、下游 · 对外接口 |
| 布局与说明 | 页面标题、文字说明（可多次） |

带 * 的 9 个是本体总览页原有的功能，直接复用原来的代码。其余模块参考了开源项目的做法，库里每个模块都注明了参考来源（WebProtégé、OpenMetadata、Superset、pyLODE 等）。

所有模块只展示本体本身，不做业务分析。

### 编辑规则

- **默认每个模块只能加一次。** 已加的模块在库里显示「已添加」，再点会定位到它在页面上的位置。
- **允许加多次的模块有四个**：类型卡片、实例表格、实例详情卡、文字说明。它们每一个都可以单独配置（比如看不同的类型），在库里标「可多次」，在页面上可以「复制一个」。
- **位置**：每个模块可以放在六个位置之一：
  - 顶部整行
  - 左上、右上
  - 左下、右下
  - 底部整行
- **左右宽度**：上排、下排的左右宽度比例可以分别调，可选 1:1、2:1、1:2、3:1、1:3。
- **顺序与高度**：同一位置里可以上移、下移；高度可以调。
- **其他操作**：撤销、保存（版本号自动加 1）。

### 查看态

- **联动**：在任一模块里点中一个类型、关系或实例，详情面板、各视图，以及标「跟随选中」的模块（类型卡片、实例卡、邻居网络、属性清单、字段映射）会一起定位。
- **可直接操作**：待确认关系可以在查看态直接确认或驳回，健康检查会跟着变；结构变化可以一键更新本体。
- **持续更新**：动态本体的数据变化会实时刷新。

### 模板与企业

- **模板 6 个**：本体审阅、动态本体监控、演示展示、质量与来源核对、上下游对接、空白应用。
- **按企业保存**：华东动力工厂、北方能源公司、实验室演示各有一套应用，切换企业就能看到各自的页面。

### 上下游的接口

- **上游**：「上游 · 中台同步」模块显示本体用到的数据中台资产，包括接入方式、调度、血缘、质量分和负责人。
- **下游**：「下游 · 对外接口」模块列出将来给下游应用用的接口约定，包括查询、时点查询、变更订阅、导出和嵌入。原型只展示约定，接口本身没有实现。

## 不包含

- 数据接入：由数据中台负责。
- 数据分析和本体应用：属于下游，是下一步的工作。
