# 平台导航演示计划

打开 http://127.0.0.1:4317/ 。建议1440×900或1366×768、浏览器100%缩放。主线约8分钟；每项均有独立入口，可跳着讲。

|编号|独立起点|操作|应看到的结果|
|---|---|---|---|
|D01|首页 `/home`|收藏本体生成与管理，收起再展开侧栏|应用收藏立即出现；收放不换页，刷新保留|
|D02|应用门户 `/portal`|选AI分类，搜索“智能体”；清空后切换业务应用|分类和关键词共同过滤；工作台与应用门户是不同入口|
|D03|搜索 `/search`|输入“领域”，方向键选中、Enter；返回后查看完整结果|打开领域本体；搜索词可恢复；完整结果可按类型和项目缩小|
|D04|文件 `/files`|按本体筛选，收藏领域本体并打开，再返回来源|只剩匹配资源；返回恢复筛选；收藏指向稳定ID|
|D05|本体 `/tool/t10?resource=ontology-domain`|探索对象→选业务分析→创建情景→选候选方案A→返回来源|能辨认工具、项目与资源；返回业务分析，不运行推理或审批|
|D06|通知 `/notifications`|选未读，打开一项，再返回；标为已读|定位关联资源；只改变阅读状态，不批准提案|
|D07|个人设置 `/settings`|时区改为上海，保存、刷新；再改一个值并取消|保存值保留；取消不会覆盖已保存偏好|
|D08|平台管理 `/admin`|修改欢迎标题，先预览、再发布；恢复上一版本|预览不改当前首页；发布后首页改变；恢复后回到原配置|
|D09|模板 `/templates?id=overview`|看四个详情页签，使用模板，不填输入先预检，再取消|浏览不要求项目；预检定位缺项；取消不创建实例|
|D10|工作台 `/workbench?view=全部`|切换三个应用视角，查看模板或空白应用创建入口|没有多余排序；四个创建/模板入口可用；已有应用可打开|

## 随机提问和乱点时的处理

- 从任何全局入口都可继续；没有规定必须先走完哪一项。
- 搜索、文件、门户条件记在URL中，可刷新、前进后退、直接分享当前入口。
- 没有记录、没有匹配、没有资源、资源失效时有对应反馈及可返回入口。
- 未保存设置离开时确认；弹窗可取消、Esc关闭。范围外业务操作在被点击时说明需要对应模块，不展示假成功。
- 若已做过演示，收藏按钮会变为取消收藏、最近列表会有记录、创建名称可能冲突，均属正常状态。不要为恢复初始画面删除真实资料；可用新的浏览器隐私窗口演示。

## 本次演示的事实边界

本次实现独立前端与本地目录交互。目录初始是按批准设计构造的固定数据，含10个资源、2个项目和2个项目组合，不是公司业务数据库。收藏、最近、资料、偏好、首页配置、文件夹、应用入口和模板实例记录保存在当前浏览器。换浏览器或源地址不会共享，服务端数据库和生产身份服务尚未接入。

通知内容来自固定事件目录，邮件偏好只保存选择，不发邮件。推广控制本地门户入口；不授予真实权限。模板创建、升级和恢复只改变本地实例目录与版本记录，不安装业务组件。专业模块中央工作区、推理、审批执行、数据连接及组件运行不在本次实施范围，点击对应操作不会伪造任务完成。

范围说明集中在本文和交付记录，不常驻产品界面。

## 验证

主验收覆盖D01–D10的全部操作，并另执行逐按钮点击、100步固定种子乱序、存储写入失败、损坏偏好、资源无权/失效、双标签同步、离线、未保存修改、浏览器进退及窄屏检查。结果见 `evidence/`；D01–D10最后还将由专用演示脚本复跑。
