平台功能导航架构与界面设计

完整审核稿 v0.2

平台保留统一的首页、侧栏、搜索、文件与应用门户。用户在这里找到工具和资源，再进入数据、本体、分析、情景、AI及应用搭建等专业模块；跨模块工作保留资源、版本和任务位置。

本稿决定入口如何组织、当前位置如何显示、如何跨工具继续和返回。各专业模块内部的编辑器、算法、表单与运行页面，待模块代码和方案核对后再决定如何接入。导航分类不改变后台架构。

架构说明图和任务流程图只帮助理解结构，不是新增产品页面。默认首页仍是实际起点；模块编写者接入规范单列于文后，不作为功能分类。

## 入口与当前位置怎样配合

首页提供清晰起点，应用门户用于找工具，文件用于按项目找资源。搜索、最近和收藏提供捷径。这些入口都打开同一资源，不各自复制一套内容。应用搭建工作台仍负责组合应用，应用门户负责找到和打开它。

| 位置 | 页面表达 | 进入与返回 |
| --- | --- | --- |
| 全局侧栏 | 深色固定入口；收藏的应用与收藏的文件分组 | 首页、搜索、通知、最近、文件、应用始终可达；收起只留图标，悬停给名称。 |
| 工具页头 | 门户分类、工具、当前资源；名称与图标一致 | 它表达资源归属，不冒充访问历史；上级名称可点击。 |
| 工具局部菜单 | 只列当前工具的栏目，当前项高亮 | 模块保留自己的内部界面；不另建一套全局目录。 |
| 返回来源 | 跨模块时显示回原任务入口 | 保留资源身份、版本与页面状态；没有来源上下文时回工具入口。 |

### AI与其他工具

独立AI分类集中放智能体、AI逻辑、评估与模型工具。数据、本体和情景模块仍可在当前任务中使用AI，不要求先切换分类。同一工具只登记一次，权限和资源共用。

### 图标和颜色

数据集、项目、本体、应用和情景使用不同形状，配合克制的分类色和中文名称。搜索框有放大镜，文件视角有类型图标，模板缩略图展示内容差别。颜色不能替代名称；灰度下仍须靠形状区分类别。

### 专业模块接入顺序

先核对组员模块的可运行页面、入口与资源身份，再保留合适的内部UI、接入统一外壳。官方原图作为导航与视觉备选；只有实际替换时才决定内部控件。数据中台和本体管理保持独立工具，无需先通过工作台搭建应用。

## 默认首页的操作与导航约定

使用者：首次进入平台的实施工程师。

1．看到按任务分组的工具卡片，而不是后台架构图。

2．点击数据连接开始准备数据；已有工作可从侧栏最近使用继续。

3．管理员从账户中的平台管理进入首页配置；普通用户不出现编辑按钮。

结果与去向：进入工具或继续已有资源；首页本身不创建项目、应用或本体。

| 控件 | 选项与默认 | 动态内容 | 操作与约束 |
| --- | --- | --- | --- |
| 工具卡片 | 按分组展示；无排序菜单 | 取已发布的工具目录，按当前访问规则过滤 | 点击打开工具首页；卡片星标独立控制收藏，不启动业务任务 |
| 欢迎信息 | 平台欢迎标题；可选组织公告 | 组织首页配置，不由模型临时生成 | 无公告时不留空占位；公告链接进入公告详情 |
| 首页配置 | 仅管理员；位于平台管理内 | 当前已发布布局及其修订记录 | 预览→发布→影响所选用户群；取消不影响用户；恢复上一已发布版本 |

### 异常与返回

新用户没有收藏和最近记录时，仍能通过默认卡片开始。工具不可用时显示明确停用说明而不是空链接；首页配置加载失败保留上次已发布布局并提示重试。

### 验收

首次进入者能找到数据、本体、AI和工作台；普通用户无管理控件；改首页预览不影响其他用户，发布后才生效。

## 全局搜索的操作与导航约定

使用者：知道名称或目标但不知道位置的用户。

1．未输入时看到最近搜索和类型入口；没有历史则显示简短提示。

2．输入后出现带类型图标、名称和位置的快速跳转建议；点击结果打开所属工具。

3．按Enter或类型入口进入完整结果；左侧筛选与顶部类型页签共同缩小范围。

结果与去向：进入匹配资源的所属工具，保留搜索条件便于返回。

| 控件 | 选项与默认 | 动态内容 | 操作与约束 |
| --- | --- | --- | --- |
| 搜索框 | 默认空；输入后搜索，Esc关闭 | 来自工具目录、资源索引与获准对象索引 | 输入后按序号呈现最新建议；上下键选中，Enter打开高亮项；无高亮项时Enter查看完整结果；Esc返回原页面 |
| 类型筛选 | 全部／应用／对象／数据集／文件；默认全部 | 可用类型按注册目录；不支持项不显示 | 默认全部；和项目条件取交集；改变条件回到第一批结果 |
| 项目筛选 | 全部授权项目／选择项目／清除 | 只列可发现的项目，支持输入检索 | 可多选，不自动把其中一个项目设为业务查询的数据范围 |
| 结果项 | 名称、类型、所属项目；无固定成功数量 | 索引返回的名称和可披露位置 | Enter或点击打开；Ctrl点击新标签；打开时再次检查权限 |
| 查看全部结果 | 有检索词时可用 | 沿用当前词和筛选条件 | 进入完整结果，不丢搜索；返回恢复词、筛选和滚动位置 |

### 异常与返回

零结果给清除筛选与改词建议；索引不可用明确“搜索暂不可用”，不伪装零结果；已撤权结果打开时阻断且不泄露内容。

### 验收

键盘能完成搜索与打开；同名数据集和对象类型能分清；旧请求晚返回不覆盖新结果；越权结果不暴露敏感摘要。

## 通知与产品更新的操作与导航约定

使用者：处理待办或关注任务结果的用户。

1．打开通知面板，按时间查看审核请求和任务结果。

2．点击某条通知进入原任务或审核详情，不额外做一份详情页。

3．查看更多进入全部通知；产品更新只承载平台版本和功能公告。

结果与去向：完成原事项或查看结果；已读与业务审批状态各自独立。

| 控件 | 选项与默认 | 动态内容 | 操作与约束 |
| --- | --- | --- | --- |
| 通知入口 | 铃铛及未读标记 | 当前用户可见的未读事件计数 | 打开面板；不因打开自动批准或执行任何请求 |
| 通知条目 | 事件标题、相对时间 | 任务/审批服务发出的事件，含稳定资源和执行标识 | 点击跳转真实详情；显示已读，不修改业务任务状态 |
| 全部通知 | 面板底部固定入口 | 同一通知流 | 进入全部通知；筛选全部／未读／待审核／任务结果 |
| 标为已读 | 单条或当前可见批次 | 通知状态 | 只改变通知阅读状态；失败保留未读并允许重试 |
| 产品更新 | 独立侧栏入口 | 平台已发布公告 | 按发布时间展示；可关闭提示，关闭不删除公告 |
| 通知偏好 | 账户→设置→通知 | 当前用户偏好 | 站内通知、邮件两渠道按事件类型配置；必要的执行结果仍保存在任务详情 |

### 异常与返回

无通知显示空态；原资源被删除说明无法打开，不反复重定向；已失效审核提示最新状态；消息服务失败可重试，不影响正在进行的工作。

### 验收

通知能回到准确资源、版本与任务；标为已读不批准请求；任务失败通知打开的是失败步骤和恢复方式。

## 最近使用与收藏的操作与导航约定

使用者：返回已有工作的用户。

1．打开最近使用，按最近访问顺序看到最多20个资源。

2．点击资源回到所属工具；常用工具或资源点星标加入收藏。

3．取消收藏只移除快捷入口，不删除资源。

结果与去向：打开原资源；浏览历史、收藏和共享资源相互独立。

| 控件 | 选项与默认 | 动态内容 | 操作与约束 |
| --- | --- | --- | --- |
| 最近列表 | 按访问时间倒序，无额外排序菜单 | 当前身份最近成功打开的资源；同一资源去重 | 点击重新检查权限并打开，最多20项 |
| 收藏星标 | 未收藏为空心，收藏后实心 | 用户偏好中的稳定资源标识 | 切换收藏；请求失败恢复原状态，不生成副本 |
| 收藏分组 | 收藏的应用／收藏的文件 | 应用入口和项目文件分别归组 | 文件名长时截断并悬停显示完整名称；无收藏给入口提示 |
| 查看全部 | 应用收藏标题旁的固定入口 | 指向应用门户 | 不跳到模板库或组件目录 |
| 失效资源项 | 失效说明及移除快捷方式 | 读取失败结果区分删除、撤权、暂时不可用 | 删除/撤权不再展示内容；可移除当前用户快捷方式 |

### 异常与返回

新用户显示简短空态；暂时离线不删除历史；资源改名同步显示新名称；撤权后隐藏敏感名称，并允许清理失效入口。

### 验收

重复打开只保留一条；改名收藏仍有效；取消收藏不改变原资源和其他用户收藏。

## 情景推演与推理的操作与导航约定

使用者：比较方案的业务分析人员。

1．从首页卡片或应用门户选择情景推演，进入同一工具入口。

2．页头显示工具与当前资源位置；左侧仅显示当前工具的局部导航。打开候选方案 A后可切换相关页签。

3．选择“提交审批”前往关联工具；用“返回来源”恢复原资源、筛选和滚动位置。

结果与去向：带稳定身份、版本和必要上下文的跳转；当前工具的内部编辑与运行由其模块方案负责。

| 控件 | 选项与默认 | 动态内容 | 操作与约束 |
| --- | --- | --- | --- |
| 工具标识与面包屑 | 应用门户→分类→工具；有资源时追加项目/资源 | 工具注册及资源目录；不是用户访问历史 | 点击上级回目录或工具入口；直链进入也可辨认位置 |
| 局部导航 | 当前工具的概览、资源列表、关联资源；当前项高亮 | 菜单由模块声明，按角色与资源能力显示 | 切换保持当前资源；无内容时给空态，不切换用户身份 |
| 返回来源 | 有合法来源上下文时显示；无来源回工具入口 | 打开页面时记录的稳定资源与页面状态 | 返回恢复筛选、选中项、滚动及草稿；失效来源给替代入口 |
| 跨模块入口 | 提交审批 | 当前资源身份、版本及允许的衔接能力 | 先检查上下文及权限；缺必要信息就地补选；不静默创建或执行 |
| 侧栏展开与收起 | 默认展开；收起保留图标与名称提示 | 当前用户导航偏好 | 切换不换页、不清条件；键盘可操作；画布重新适配宽度 |

### 异常与返回

入口加载失败可重试；空列表不制造假资源；无权或已删除资源不泄露摘要。深链接失效时给工具入口，返回来源失效时保留当前工作。未保存修改按保存并离开、放弃并离开、取消处理。

### 验收

从门户、文件和深链接进入均能识别工具与资源位置；侧栏可收回；跨模块后可回到原资源；内部UI替换不改变全局入口和资源身份。

## 跨板块跳转与返回

跨工具跳转应像接力：传递的是同一资源的引用和工作上下文，不是把数据再抄一份。上下文就是当前项目、数据、本体版本、选中的对象和正在处理的任务。

| 交接 | 触发 | 带过去什么 | 到哪里及失败处理 |
| --- | --- | --- | --- |
| 数据→本体 | 输出数据集详情点生成本体 | 数据集身份、明确版本、来源与质量摘要 | 本体生成；完成可返回同一数据集。无权或数据过期先提示。 |
| 本体→探索 | 已发布对象类型点探索对象 | 本体发布版、对象类型与允许的初始条件 | 对象探索；返回同一类型详情。草稿不作为生产事实。 |
| 探索→情景 | 选定集合后点创建情景 | 对象集合定义、数据快照、本体版本、当前筛选 | 创建情景；返回恢复对象条件。无可用模型先说明，不生成假结果。 |
| 情景→审批 | 比较结果点提交审批 | 基线、假设、规则模型版本、证据、风险与变化清单 | 审批详情；退回后回原候选修改，旧批准不能复用。 |
| 专业工具→工作台 | 在工作台中使用 | 稳定资源引用、结果类型、版本、允许的能力 | 已有应用先选目标或新建；回原工具不丢进度。复杂配置仍可在专业工具打开。 |
| AI→各模块 | 智能体调用工具或引用结果 | 授权范围、明确输入、必要的本体与情景上下文 | 执行后返回结构化结果及来源。发布、审批与执行保留原规则。 |
| 工作台→门户 | 发布后推广应用 | 已发布应用身份、入口、名称图标、目标用户群 | 门户打开运行态；不把搭建草稿暴露给业务用户。 |
| 模板→项目 | 决定使用后安装 | 模板版本、目标项目、输入映射、权限确认 | 安装记录与产物。依赖缺失可去补齐再返回原安装进度。 |

| C02 资源注册 | 声明资源类型、稳定身份、名称、项目、所有者、打开方式、修改时间、版本及生命周期。机器标识稳定，显示名称可改。 | 资源改名后收藏、依赖和通知仍可打开。 |
| C03 页面导航 | 定义工具首页、资源列表、资源详情、编辑与运行入口；标明面包屑和返回目标。全局与局部导航名称一致。 | 从深层链接进入仍能识别位置并回到工具首页。 |

| C06 通知接入 | 定义值得通知的任务/审批事件、接收者、去重键、资源和执行跳转、阅读状态；不把每次点击都发通知。 | 一次任务只产生相应事件，打开落到同一执行。 |
| C07 上下文传递 | 声明接受与返回的项目、数据、本体、对象集合、时间、情景及版本；缺必需信息时明确选择，不猜。 | 跨部门对象按授权关系连接，不让用户勾全公司表。 |
| C08 权限一致 | 每次读取、查询和写入由业务服务验证身份及范围；隐藏菜单仅改善体验。嵌入和MCP沿用同一规则。 | 换入口不能扩大数据或操作权限。 |

## 工作台组合与 MCP 适用性评估

工作台让人把能力拼成页面；MCP让Agent找到并调用获准能力。两者都是使用入口，实际业务逻辑由同一服务负责。专业工具无需把完整界面塞进画布，也无需为Agent复制一套业务代码。

每个模块必须做适用性评估。可复用能力提供标准接口，适合直接操作时再提供可视组件；底层存储、内部计算步骤、展开菜单和拖动分隔条不必逐个组件化或工具化。

| 板块 | 可复用能力 | 可视组件例子 | MCP评估结论示例 |
| --- | --- | --- | --- |
| 数据中台 | 读数据与质量、启动获准管道、任务进度 | 数据选择器、质量卡、运行进度 | 搜索与读结构适合；执行管道有任务与权限；凭证管理不默认开放 |
| 本体与语义 | 生成候选、查类型、版本差异、提案 | 本体选择器、候选审核、差异与状态 | 生成/查询适合；发布取决于角色与审批，不让模型自行批准 |
| 对象探索与分析 | 查询对象集合、关系、时序和指标 | 表格、关系图、趋势、筛选器 | 适合查询，需明确时间/单位/口径/部分结果；不能只返回难核对的长文 |
| Scenario与推理 | 创建隔离情景、设假设、运行、比较 | 情景选择、参数、比较与依据 | 适合组合多步任务；必须区分情景内变化与live执行 |
| AI | 获准智能体、AI逻辑、评估任务 | 聊天、AI结果与引用 | 可将已发布助手作为工具；限制递归调用和预算，防无限互调 |
| 审批与Action | 提交申请、查看决定、获准后执行 | 待办、批准、执行收据 | 可提交或读取，批准由指定角色完成；不把人类批准伪造成Agent工具结果 |
| 应用工作台 | 读组件、生成应用草稿、配置和检查 | 工作台本身消费组件合同 | Agent可辅助搭建；发布和推广按权限，布局拖拽不必等同MCP工具 |
| 实施与治理 | 预检、安装、审计查询、恢复任务 | 安装进度和运行状态 | 逐项受控评估；跨组织迁移、授权和恢复不能默认全部开放 |

### 接入合同怎样避免各写一套

模块先声明业务能力：用途、输入、输出、权限、版本和错误。工作台组件通过这份合同绑定数据和操作，MCP适配层用相同合同发布工具。MCP是Agent的标准调用入口，不是新的业务引擎。工具数不与按钮数一一对应，多个页面可以调用同一业务能力。

| 共同信息 | 必须表达的内容 |
| --- | --- |
| 输入与输出 | 资源引用、对象集合、表格、数值、文字、时间、空间位置、结构化记录和任务引用均可声明；明确必填、单位、时区及空值含义。 |
| 统计与时间 | 指标名称、计算定义、分组、时间窗口、过滤、单位及来源随结果传递；不能把“3笔”之类固定摘要写死。 |
| 事件与状态 | 组件发出对象选择、范围变化、动作提交等事件；宿主定义传递方向，处理循环触发。状态注明个人会话或共享持久、恢复和过期规则。 |
| 生命周期 | 加载、挂载、暂停、卸载和资源释放；嵌入对象变更时清理旧请求，防止旧响应覆盖新上下文。 |
| Agent可用说明 | 用途与不适用场景、参数结果、可见范围、副作用、确认要求、重试及任务跟踪；同义工具可发现但不重复实现。 |

### 用三个不同组件检验通用性

地图需要空间位置与范围事件；统计卡需要可追踪口径与时间范围；聊天需要会话、引用和工具状态。它们可使用不同输入类型，但都遵守同一权限、版本、事件、状态和生命周期入口。新类型通过有版本的能力声明扩展，不把地图坐标或聊天消息硬写成所有组件必填项。

## 角色与端到端验收

同一平台保留相同的全局入口，但按任务和权限呈现不同内容。普通业务用户不因使用一个已发布应用就必须学会搭建器、模型配置或本体编辑。

| 角色 | 默认主要路径 | 不应被迫经历的步骤 |
| --- | --- | --- |
| 实施工程师 | 首页/门户→数据→本体→分析/推演→应用→交付 | 不为每个可信组件重复申请项目启用 |
| 数据工程师 | 文件/门户→连接或管道→预览→质量血缘 | 无需先搭Workshop应用才能整理数据 |
| 业务专家 | 通知→候选提案→依据与差异→审核决定 | 不必进入模型和连接凭证设置 |
| 分析与决策人员 | 搜索/业务应用→对象→情景比较→审批 | 无需先手选公司全部数据表 |
| 管理员 | 账户/门户→管理→权限、首页、模型和运行 | 不在普通首页常驻所有管理表单 |
| Agent | 获准工具目录→查询/任务→证据结果→必要审批 | 不能凭MCP入口获取超出调用身份的权限 |

### 跨板块验收路径

下列是实施后的产品验收要求。静态导航图不证明业务能力已经实现；接入时须用匹配能力的真实数据及已知答案另行核对。

| 验收编号 | 用户路径 | 必须核对的结果 |
| --- | --- | --- |
| V01 从数据到发布本体 | 打开一个实际获准数据集→生成候选→人工审核→发布→探索对象 | 资源和版本贯穿；候选未批准不成为事实。 |
| V02 从事实到受控执行 | 固定对象集合→建情景→修改假设→运行→比较→审批→执行 | live未提前改变；审批与执行收据分别可见。 |
| V03 从组件到业务入口 | 发现可信组件→绑定数据/逻辑→预览→发布→推广门户→普通用户运行 | 目录、草稿、发布版区分；未授权数据仍不可见。 |
| V04 跨板块恢复 | 运行中离开→通知返回→失败定位→修复重试 | 回到同一任务；不生成重复副作用；恢复筛选与草稿。 |
| V05 跨身份和版本 | 收藏资源后撤权/改名/升级，再从搜索、最近与MCP打开 | 改名不断链，撤权有效；版本变化有说明。 |
| V06 模板阶段隔离 | 浏览模板→预览→决定使用→目标项目→映射→预检→安装 | 浏览不要求凭证/项目；失败有已创建资源清单和续接。 |
| V07 通用扩展 | 地图、统计、聊天组件接入同一工作台；替换另一行业对象 | 不改全局导航核心，不引入固定行业字段。 |
| V08 Agent实际使用 | 用同一任务分别由人和Agent调用查询/长任务/写入提案 | 事实结果一致；权限、审批、防重复和错误都可复现。 |

导航分类不决定后台部署位置。规则与Function在本体语义中管理，可被数据、Scenario、AI和应用使用；Action在语义层定义，在审批与运行时执行；向量检索是查询能力，不要求业务用户先选向量数据库。备份、容量和恢复属于管理职责，不混进普通用户主流程。

数字孪生是部分行业可用的应用形态，不是所有用户的必经入口。T2所需时间推进、暂停、快照和状态迁移位于情景工具内按模型能力出现；未使用该能力的简单查询不显示这些设置。
