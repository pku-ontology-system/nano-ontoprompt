# ADR 0021：按任务分组的一级导航 + “当前本体”选择器

> 日期：2026-10-23 · 状态：已采纳

## 背景

- 提交 `0f13c58` 参照 Foundry 把导航分成两层：全局侧栏只有首页、本体库和几个应用；进入某个本体后，再用本体页里的二级导航（总览 / 资源 / 数据 / 应用 / 治理，约 16 项）找功能。
- 结果是大部分功能藏在第二层，要先进本体页才能看到。
- Workshop 应用（`/apps/workshop`）不在任何导航里，只能手敲地址。

## 决定

1. 左侧一级导航按“用户正在做什么”分组：数据接入 / 本体建模 / 探索 / 推演 / 应用 / 告警 / 智能体，另设“系统管理”。首页、本体库保留在最上面。每一项都指向已有页面，不新增功能（对照表见 `frontend/src/components/navigation.ts`）。
2. 顶栏加“当前本体”选择器，取代“先进本体页、再用二级导航”。本体页里的二级导航和本体切换下拉删除。
3. 当前本体的来源：地址里的本体（`/ontologies/:id`、`?ontology=`、`?ontology_id=`）优先，否则用上次的选择（localStorage，读写失败时忽略）。切换本体时停留在同一个功能。
4. 没选本体时，需要本体的入口打开“先选择本体”页（`/apps/<功能>`），选完直接进入该功能。
5. 旧链接不变：`/ontologies/:id?tab=…`、`/apps/objects`、`/apps/alerts` 等仍打开原页面，路由没有改。

## 理由

- **Foundry 原则不变**（官方文档）：对象浏览器、告警、情景等都是“跑在某个本体上的应用”，所有页面仍然以本体为范围；改的只是入口，从两层压成一层。
- **按任务分组的一级导航**（第三方产品截图：OntoFlow，见 `docs/research/unofficial/ONTOFLOW_TWIN_APP_BUILDER_2026_10_22.md`）：用户按要做的事找功能，不用先记住功能属于哪一层。
- **选择器放顶栏**（本项目推断）：本体是所有页面共享的上下文，放在顶栏随时可见、随时可换，比藏在某个页面里更直观。

## 取代关系

取代提交 `0f13c58` 中**导航部分**的决定（全局侧栏只放平台级入口 + 本体页内二级导航）。该提交的其他决定继续有效：数据从本体内的“数据源”进入、供应商演示改为已保存的情景研究、旧的 `/what-if` 跳转等。

## 影响

- 侧栏条目从 8 项增加到约 22 项，在 800px 高的屏幕上需要滚动；当前所在项会自动滚到可见位置。
- 本体页 `OntologyDetailPage` 只负责渲染选中的功能，不再自带导航；新功能要出现在导航里，需在 `navigation.ts` 里加一项。
- 全局的 `/scenarios`（通用情景目录）不再出现在侧栏，由“推演 → 情景沙箱”（`/ontologies/:id/scenarios`）替代，旧地址仍可打开。
- e2e 用例 `ontology-navigation.spec.ts` 已按新导航更新。

## 更新（2026-11-09）：撤下四个没有做成的入口

侧栏从 25 项减到 21 项。逐项在演示环境（11 个本体）里实际打开、点运行后，撤下这四项：

| 撤下的入口 | 实测情况 |
| --- | --- |
| 业务数据 | 11 个本体都没有 frePPLe 导入记录，页面只显示空状态；后端只有读取接口，没有导入入口，界面里填不出来 |
| 逻辑规则 | 只读列表，11 个本体里逻辑规则都是 0 条，没有新建入口；页面唯一的按钮转去“函数” |
| 决策分析 | 目录接口返回空列表（三个基准样例本体都没装，安装脚本要先下载公开数据集），页面只剩一个指向木材供应旧演示的链接 |
| 动态演化（实验） | 自带“实验”标记，只对时序本体显示，当前没有可演示的数据 |

页面、标签页和路由都保留：`?tab=manufacturing`、`?tab=logic`、`?tab=dynamic`、`/decision-lab` 仍可打开，别处指向它们的链接（数据源页的“业务数据”卡片、时序回放页的“动态演化”按钮、对象浏览器里的决策分析链接）不变。数据或功能补齐后，在 `navigation.ts` 里加回一行即可。e2e 用例新增断言：这四项不再出现在侧栏。

仍保留但需要先有数据才有内容的入口（实测能用）：推理验证（引擎能跑，需要先有规则；当前没有已发布的逻辑规则，要手写）、本体查询（目前没有保存的查询，新建入口在 Workshop 编辑器里）、告警中心、决策与影响链、智能体决策（确定性整理可用）。

## 更新（2026-11-09，之二）：分析、探索、推演类入口先从侧栏暂时隐藏

决定：这批页面先收起，改为照开源项目的做法重做几项“本体建好之后的分析”，并用这些项目自带的演示数据展示（调研见 `docs/research/unofficial/OSS_ONTOLOGY_ANALYSIS_SURVEY_2026_11_09.md`）。侧栏暂时隐藏 14 项：函数、本体查询、质量审查、对象浏览器、关系图、情景研究、情景沙箱、决策与影响链、推理验证、Workshop 应用、告警中心、运行规则、智能体决策、模型与审查。留在侧栏的是：首页、本体库、数据源、本体总览、对象类型、数据模型、设置。

- 只改侧栏：页面、标签页、页面里的链接、`/apps/<功能>` 选本体页和后端都没动，旧地址照常打开。
- 隐藏名单在 `navigation.ts` 的 `TEMPORARILY_HIDDEN`，删掉某个 key 就恢复那一项。
- 临时查看：地址后加 `?nav=all` 会显示全部入口并记在当前浏览器里，`?nav=default` 恢复隐藏。e2e 里测完整导航的用例先开这个开关；新增一条用例检查默认状态和开关。
- 和上一条“撤下四项”不同：撤下的四项是做不成，从导航表里删掉了；这 14 项是能用但先不展示，导航表里的条目还在。

## 更新（2026-11-09，之三）：新增“数据分析”分组

侧栏在“本体建模”之后新增“数据分析”：数据健康、实体消歧、数据血缘、流水线演示（`/analysis/*`，全局页，不依赖当前本体）。它们不在隐藏名单里。设计和取舍见 [ADR 0022](0022-analysis-after-construction.md)。现在默认可见的是：首页、本体库、数据源、本体总览、对象类型、数据模型、数据健康、实体消歧、数据血缘、流水线演示、设置。
